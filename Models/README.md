# Runtime models

These unmodified models are included so the game does not need to download them on first run.

| File | Source | Licence |
|---|---|---|
| `face_detection_yunet_2023mar.onnx` | [OpenCV Zoo, YuNet 2023mar](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet) | [MIT](LICENSE-YuNet.txt) |
| `face_recognition_sface_2021dec.onnx` | [OpenCV Zoo, SFace 2021dec](https://github.com/opencv/opencv_zoo/tree/main/models/face_recognition_sface) | [Apache 2.0](LICENSE-SFace.txt) |
| `pose_landmarker_full.task` | [MediaPipe Pose Landmarker Full, float16, version 1](https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_full/float16/1/pose_landmarker_full.task) | [Apache 2.0](LICENSE-MediaPipe.txt) |

The [setup instructions](../README.md#restore-models-optional) explain how to restore missing files. The Lite model is only used for optional comparisons and is not included.
